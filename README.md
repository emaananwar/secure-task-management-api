# Java System Health Monitor

A lightweight Java-based system monitoring application that periodically collects and displays system performance metrics such as CPU usage and memory utilisation. The project demonstrates practical use of JVM and OS-level APIs, scheduled execution, and debugging platform-specific behaviour

## Features
- Periodic system health monitoring (every 5 seconds)
- CPU load and memory usage collection
- Uses Java Management APIs ('OperatingSystemMXBean)
- Cross-platform aware (Windows/Linux behaviour handled)
- Simple, clean project structure
- Command-line execution

## Technologies Used
- Java (JDK)
- JVM Management APIs
- Command-line interface
